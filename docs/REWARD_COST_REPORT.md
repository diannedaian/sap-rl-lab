# 奖励成本对照：救回空队失败，但还不是稳定配方

**本轮完成并复核。仅换位扣分让两个原本直接认输的模型开始正常购买、拿到
胜场，但仍有冻结循环，未通过预定筛查。暂不替换旧模型或确认扩张 recipe。**

A：每动作 −0.005；B：仅换位 −0.005。三个配对种子，每模型固定 2,097,152
步，其他设置相同。以下为**最终权重**，每模型五家族各 200 局。

| 种子 | 无购买零胜失败率 A → B（最差家族） | 平均胜场 A → B（五家族等权） | 强制局率 A → B（最差家族） |
| --- | --- | --- | --- |
| 17301（已知故障） | 100% → 0% | 0 → 3.305 | 0% → 12% |
| 203101 | 100% → 0% | 0 → 2.729 | 0% → 14% |
| 203201 | 0% → 0% | 3.238 → 3.052 | 7% → 12% |

前两行 A 的零强制是因为几乎只按结束回合，不是好策略。第三行 B 没有更强。
六个最终模型对两个学习型测试家族的十胜率**全部为 0%**；B 平均能拿到的
学习型胜场分别为 2.233、1.890、1.838，但尚未达到十胜终点。
所以“学习型十胜率差均非负”只是 0 对 0，不能解释成已证明强度不退步。
脚本三家族平均十胜率 A → B 分别为 0% → 3%、0% → 1.17%、7.33% → 4.17%。
这是约 210 万步的小试，不能直接与上一轮约 839 万步成熟模型的胜率比较。

## 我们真正学到了什么

- **每动作罚款确实值得警惕。** 两个配对实验中，去掉非换位动作成本后，
  空队失败消失，购买和平均胜场恢复。它支持早期“少操作、便宜地输”的解释。
  但 B 同时改变了购买、冻结、刷新、结束回合等成本，不能把原因只归于购买。
- **仅罚换位会遗漏冻结循环。** 种子 203201 每局换位从 31.63 次降到 10.25 次，
  冻结却从 5.67 次升到 28.24 次；强制局率上升，平均胜场下降。
  回放也看到了真实重复冻结，而不是把所有重复动作都主观判为错误。
- **训练曲线仍在变化，不是已经练到上限。** 三个 B 从约 52 万步到最终的
  验证强制率分别从 76%/85%/76% 降到 12%/18%/11%。有进步，但当前未达
  2% 筛查线，也不能靠外推曲线保证继续训练就会成功。

13 个最终验证回放全部精确复现，1,294 个动作的实际奖励逐步核对一致。
例如 B/203201 的一个失败回放有 70 次冻结、1 次强制；触发强制的冻结概率
为 75.4%。A/17301 则六次结束回合直接输，最后结束回合概率约 99.999%。
value 是状态期望回报，不是动作 Q 值；单次胜局的实际回报高于 value，
不能单凭这一点宣称 critic 有 bug。回放是结果挑选的诊断样本，不估计总体比例。

## 中途最佳与边界

沿用原选模规则的最佳权重也没有推翻结论：17301 的两臂与最终测试表现相同；
203101 的 B 平均胜场 2.734、强制 15.5%，仍未解决；203201 的 B 平均胜场
3.088、强制 13%，学习型仅 1/400 局十胜（0.25%）。最后一个最佳版本还出现
1/200 个 summon 家族回合数截断：9 胜、5 负、16 平，30 场后达回合上限，
不是 30 次购物动作强制战斗；该局没有强制战斗。不能隐去它，只报最终零截断。

这轮三种子含一个已知故障；五个测试池是上一轮分析过的对手，只换新局种子，
不是独立泛化确认。全部 12,000 个测试记录的邻近回合对手回退发生在脚本家族，
学习型家族没有回退；这不等于学习型后期样本足够多。最终 A/203201 有 13 次
回退，B/203101 有 1 次、B/203201 有 3 次，其余最终模型为 0。

**决定：不把 B 当成已确认的新配方，不自动启动长训练。** 我们得到的是
“减少早期放弃，但循环和实力仍待解决”的诊断结果，不是项目学不会或已修好。

证据：`runs/reward-cost-pilot-v1`。六模型实际训练共 **12,582,912** 步，
36 个准确验证权重、14,400 条曲线、4,800 条重载、12,000 条测试均已核对；
逐家族配对区间、全摘要、初始配对与预定筛查重算一致。
回放证据：`runs/reward-cost-pilot-audit-v1`。训练源代码、规则、数据、选择未改，
未使用 GPU/集群、发布、清理或替换旧交付。完整预案见 [REWARD_COST_PLAN](REWARD_COST_PLAN.md)。
