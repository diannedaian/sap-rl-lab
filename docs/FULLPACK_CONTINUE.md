# 继续训练而非在预算边界等批准

用户再次明确持续训练到完整包80%。本轮先给三条现有Tier5谱系各续1,048,576步，
不修改已有环境、奖励、KL0.01、优化器超参数、对手池或验证集，不读取测试成绩。
从最新保存权重（A36.5%、B39%、C29%的验证状态）继续；旧合格模型不删除。
每段用新优化器与新训练随机种子；第一次验证必须逐行复现父检查点，之后才允许更新。

5%强制率仍是交付选模门槛，不再将略高于5%连续两次等同于必须停止学习。
严重退化停训条件预先固定为连续3次验证出现以下任一项：

- 任一家族强制局率超过50%；
- 任一家族不买宠物且零胜失败超过25%；
- 两个学习型验证族平均十胜率比本段峰值下降超过20个百分点，且峰值至少30%。

真正截断或程序异常仍停下核查，不自动放宽40回合上限。上述停止标准是本项目的
操作选择，不冒称统计显著性或行业常数。合格选模仍沿用更严格的原始规则。

此次3,145,728步只是一个有界工作段，不是整体目标的终点。CPU最多两个worker、
单段4小时上限。完成后推进Tier6全开放；不能以Tier5的80%或最强单seed替代最终
三支验证选模模型对独立学习型测试的平均80%。达到后还需未看过的确认评估。
