# 80%延长训练：单支82.8%，整体未过线

2026-09-14。**预声明验收未通过，已停止，没有开展下一层Tier准备或追加训练。** 这次主要是提升不一致，不是大面积训练崩坏。

三支各追加2,097,152决策，共6,291,456步；本机CPU训练、验证、测试和回放审计共 **36分32秒**。KL、奖励、规则和对手池均未改，无新BC。旧模型和全部证据保留，未自动替换交付。

## 结果

下表每格为同一新测试上的学习型对手十胜率：每模型两个族各500局，共1,000局。不是单场战斗胜率。

| 来源种子 | 本轮起点 | 追加训练终点 | 验证选出的版本 |
|---|---:|---:|---:|
| 17301 | 70.3% | 77.4% | 70.3%（起点） |
| 204101 | 76.6% | 76.4% | 76.6%（起点） |
| 204201 | 78.2% | **82.8%** | **82.8%（终点）** |
| 三支平均 | 75.03% | 78.87% | **76.57%** |

主要验收为最后一列：**2,297/3,000局十胜，低于所需2,400局，差103局**。固定终点2,366/3,000，也没到80%。不能只挑82.8%宣布“三种子80%基线成立”，也不能用测试把前两支换成别的检查点。旧报告75.92%来自另一批测试局；本表重测起点75.03%，才是本轮同测集比较。

## 为什么训练进步了，选模却不全选新版本？

17301在学习型测试上提高7.1个百分点，但四族验证宏十胜率从96.25%降到94.75%；204101从96.00%降到95.25%，所以原规则保留起点。204201验证95.00%→96.75%，因此选终点。**验证排序与学习型测试目标不完全一致**值得后续检查；这不是现在改规则、拿测试重选的理由，也尚未确定差异来自分布、有限样本还是其他因素。

可靠性通过：三个选模的强制局率分别 **0.04%、0.36%、0.04%**（各2,500局）；合计11/7,500≈0.15%。所有比较模型无截断、无不购买零胜失败，修正后的换位/冻结行为代理也均在门槛内。但82.8%模型的一个失败回放仍连续冻结9次、最高概率97.87%，所以低强制率不等于零循环。

**学到的是：继续训练能让部分种子更强，已有一个按验证选出的82.8%候选；但还没有稳定复现三支平均80%。按约定到此停止。** 40宠物、普通商店Tier1–3、Tier4升级奖励的范围不变。

核验：27份精确检查点、36,900条曲线/重载/测试记录独立复算、14份诊断回放/1,448动作、24个worker全部正常退出。测试前发现的冻结字段漏计已通过独立复核纠正，**不改变十胜率或本轮不过线的结论**。[详细证据](KL_80_EVIDENCE.md)；[统计勘误](KL_80_METRIC_ADDENDUM.md)。
