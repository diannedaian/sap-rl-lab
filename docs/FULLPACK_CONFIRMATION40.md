# 完整包最终确认：固定新对局，不重新选模型

在Tier6候选成绩产生之前固定本流程。实现为`scripts/confirm_fullpack_tier6.py`。
不会修改已经运行的训练配方、检查点或封存协议。

- 仅在完整60宠物、Tier1–6商店、40回合的三模型测试筛查通过后执行。
- 先从逐局证据复算原筛查，核对选模、模型文件、权重和对手池哈希。
- 三支模型沿用原验证集选中的固定权重；不挑最强seed，不再训练。
- 对原5个测试家族，每模型每家族500局，固定新种子171000000–171000499。
  两个学习型家族合计3,000局，全部家族合计7,500局。
- 学习型三模型平均十胜率≥80%；每模型每家族强制局率≤5%、无整局截断、
  零胜且从未购买宠物的失败率≤5%。判据与原筛查一致。
- 固定输出`confirmation171-v1`，拒绝覆盖或无声重抽种子。若失败，保留并报告，
  不能把它藏起来重复确认直至通过。
- 这是新对局、原冻结对手池的复测，不是全新打法、真实竞技场或官方客户端一致性验证。
  80%是点估计，不是要求置信区间下界超过80%；模型共享对局种子，不能把所有观测
  无条件视作独立样本来给出过于乐观的置信区间。
- 数字通过后仍需规则覆盖、训练配方、三模型选择、步数/时间和限制的最终交付审计。
  确认工具始终保留`goal_complete=false`，不替代主任务的完成判定。
