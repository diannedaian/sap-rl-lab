# 脚本模仿 → PPO：夜间独立实验（2026-09-09）

用户授权：实现“先模仿正常玩法，再用 RL 提升实力”，保留旧最好模型，晨间解释教了什么、PPO 做了什么。不发布、不覆盖、不清理、不用集群。

## 要回答的问题

同一环境、网络、奖励、训练对手和 PPO 预算，脚本行为克隆初始化能否减少不购物就输光的失败，并帮助 PPO 学到更强的策略？模仿会不会仅复刻老师的局限，或者被 PPO 遗忘？这是有界方法对照，不承诺解决稳定性或证实完整 Turtle 泛化。

## 固定设计

- 仍是 v5 的 40 宠物开发沙盒：普通商店到 Tier 3，Tier 4 只作真实升级奖励。不是完整 Tier 4 商店，更不是完整 Turtle。
- 三个已有教师：midgame_stats / midgame_summon / midgame_tempo。分别偏重数值、召唤、节奏。各收集 600 局训练、100 局监督验证：共 1,800 / 300 局。包含所有胜负局和动作，不挑成功示范。
- 教师只用当前自身公开状态，不看未来随机结果或测试对手。现有教师不使用冻结；模仿不能证明掌握冻结策略。三教师没有风格标签输入，可能给相近状态不同动作，这是有意保留的混合示范局限。
- 保存动作前观察、合法动作掩码、动作标签、教师、整局 seed 和边界。按整局隔离监督训练/验证；验证不回流训练。两者均对训练池采样，不读取测试池生成示范。
- BC 只训练 actor：合法动作上的负对数似然，不使用胜负 reward，不训练 critic。20 epochs、batch 512、Adam 3e-4、eps 1e-5、gradient norm 1。网络保持原有 64×64 MLP，不改编码器。每个 epoch 保存独立权重；选第 1–20 epoch 中监督验证交叉熵最低者，平局取最早。epoch 0 仅为随机初始化参照。不按测试/对局胜率挑 BC epoch。
- 三个种子：17301（已知故障复现）、204101 / 204201（新种子）。每个种子的随机对照与 BC 从同一初始 actor/critic 出发；BC 保留 critic 原值。PPO 两组都重建优化器并重置相同训练 RNG；不携带 BC Adam 动量。
- 先用独立闭环验证，每个 BC / 随机初始模型 4 对手族 × 100 局。同一个 BC 模型自己连续决策，不由教师纠正。所有三种子均须：最差族不购物零胜失败 ≤5%，最差族强制开战局 ≤20%，无截断，宏平均胜场 ≥1 且比初始模型至少多 0.5 胜，才进入 PPO。此处是基础能力/预算筛查，不是交付质量阈值。任何种子失败则整轮暂停在 BC，报告失败，不换阈值、不偷偷重训。
- 通过后，3 对模型，各 8,388,608 次 PPO 决策，共最多 50,331,648 次；BC 示例访问次数和生成成本另记，不声称总算力相等。选此长度是为避免仅用 210 万步便断言方法无效；与旧强模型训练长度一致。
- PPO 沿用 all-action cost 0.005，swap extra cost 0，entropy 0，无新成功 bonus。原始胜负/终局奖励不改；30 次动作强制开战；6 个训练池等权（3 脚本 +3 历史学习型），8 环境、rollout 256、batch 256、lr 3e-4、gamma 1、GAE 0.95，原 MaskablePPO 默认 10 epochs / clip 0.2 / value coefficient 0.5。BC 后是纯 on-policy PPO，不继续混入监督 loss，不加入 KL/DAgger 等第二种方法。
- 每 1,048,576 步验证，保留每次验证的精确权重；同一步最后一次更新前后分别记录。沿用原 win-first / worst-family / forcing / return 排序，仅作次要“验证最好”比较；主要比较固定预算最终权重，避免只呈现最好曲线点。
- 测试前冻结 12 份 PPO 最终/所选 +3 份 BC-only +1 份旧最佳，共 16 份。全部独立重载验证 4×100 局且逐局一致后，才打开 5 族×200 局的诊断测试，共 6,400 重载 /16,000 测试局。
- 监督训练 seeds 从 28,000,000 起，监督验证从 29,000,000 起；每教师偏移 100,000。闭环验证从 30,000,000，测试从 31,000,000 起。游戏测试使用以前研究过的对手池，仅换局随机 seed；不宣称全新对手生态、独立确认。
