# KL 刹车晨报 · 2026-09-13

**这轮有实质进展：相同步数下，三个 KL 模型都更强，强制开战也明显减少。但还不能说“以后不会训崩”。**

## 结果

六个模型统一比较追加训练 **1,835,008 步**的检查点。十胜率针对两族学习型对手，每模型400局；强制率指五族对手共1,000局中，至少一次用完30动作、被强制开战的局数比例。

| 来源种子 | 原 PPO 十胜率 → KL | 原 PPO 强制率 → KL |
|---|---:|---:|
| 17301 | 56.25% → **65.00%** | 9.1% → **0.1%** |
| 204101 | 63.50% → **71.00%** | 13.7% → **0.2%** |
| 204201 | 63.50% → **72.50%** | 0.1% → **0%** |
| 三种子平均 | 61.08% → **69.50%** | 7.63% → **0.10%** |

KL三支的起点十胜率分别54.25%、53.75%、52.25%，所以不只是保住旧水平，确实有提高。旧历史最佳在同一测试为59.75%；没有覆盖它。

## 训了什么，为什么有帮助

没有新老师数据、没有再做BC。拿之前三个 **BC→PPO已训练315万步**的健康版本，各分两支继续PPO；唯一算法差异是`target_kl=0.01`。奖励仍是战斗胜+1/负−1，每动作−0.005。

共同训练区间中，实际策略KL中位数从约0.027–0.040降到约0.009；三支KL的实际梯度更新总数减少约71%。每局平均换位从57.6降到28.2次，冻结切换从16.8降到4.8次。**更新更保守，与循环减少同时出现；不是加了新惩罚。**

仍有反例：一个KL成功回放154步里换位105次，触发强制开战时仍以99.69%概率选换位。因此刹车明显缓解问题，但没有消灭循环，也尚未验证更长训练是否会再次退化。

## 必须保留的限制

- 原计划六支各209.7万步；运行中断后五支完成、一支未完成。用户授权继续后，按所有模型都有的最大保存点183.5万步恢复评估，**零新增训练**。这是中断后的修订，不冒充完整原预注册结果；具体退出原因未被原日志保存。
- “验证选出的最佳版本”优势没有主要比较那么一致：KL只在2/3对胜出，第三对67%低于原PPO的71.5%。验证排序不保证测试排名相同，不能看完测试再挑赢家。
- 仅三对、已研究对手池的新局seed。当前仍40宠物、商店Tier1–3、Tier4仅升级奖励，不是全Turtle Pack。

**建议：把KL刹车保留为下一轮候选配方，先锁定它再做独立种子/更长时程确认；这晚不追加实验。** 不再同时改奖励或加BC约束，避免分不清改善来自哪里。
