# KL 保留：新采样种子与更长训练

2026-09-13，用户已批准下一轮。此计划先于新训练/验证/测试冻结。目标是检查上一轮的保守更新收益能否在新采样随机性、更长时程重现，不扩环境、不调新超参、不替换交付。

## 固定设计

- 三个起点仍为 `imitation-v1/bc-seed{17301,204101,204201}/validation_weights/eval003.zip`，各自已经过 BC→PPO 3,145,728 步。不是从上轮看过测试的赢家继续。
- 每个起点分原 PPO / PPO+KL 两支，配对使用新采样 seed 97301、97302、97303；同 actor/critic 权重、新优化器。**独立的是本轮采样随机性，不是三份全新 BC 初始化，也不是新对手生态。**
- 每支恰好追加4,194,304个环境决策；6支共25,165,824。相对于上轮共同183.5万步，观察时长约2.29倍；加起点合计约734万步。不是同梯度更新次数比较。
- 唯一算法差异：`target_kl=None` / `0.01`。保留学习率3e-4、10 epochs、clip0.2、entropy0、gamma1、GAE0.95、batch256、8环境×256步、Torch单线程。沿用同一训练器和PPO实现，不改旧源文件。
- 40宠物、普通商店Tier1–3、Tier4仅升级奖励；胜+1/负−1/平0，每动作−0.005，30动作强制战斗。六训练池等权，旧四族验证/五族测试池不变。

## 评估与解释预先约定

- 每524,288步验证一次，加起点共9次/模型；每次4族×100局，验证seed35,000,000。记录全曲线、每次对应精确权重、实际KL/梯度次数、critic及按动作GAE。
- 主要比较固定终点4,194,304步。另保留固定中点2,097,152步，直接衡量后半段变化；验证选出的合格检查点为次要比较。禁止事后以测试成绩选新赢家。
- 选择规则完全沿用ValidationGuard：每族强制局率≤5%、不购买零胜失败≤5%、无截断、宏平均至少1胜；按宏十胜率/最差族十胜率/负最差强制率/原始回报排序；任一族较保留模型跌超10个百分点则阻止替换，平分保留较早。5%为本轮诊断粗筛，不是行业或最终交付标准。
- 普通退化只记录，不提前停其中一支，以比较完整预算；数值异常、截断、时间限制停止并明确未完成。不自动回滚、续跑、调参或扩预算。
- 六终点、六中点、最多六验证选择、三个初始、历史最佳，共最多22个比较。全部冻结后，全部精确重载验证（最多8,800局）才统一测试。测试5族×200局/模型、seed36,000,000，最多22,000局。
- 逐对报告学习型对手整局十胜率与强制局率、中点到终点变化、相对起点变化；不只报告平均值或最好模型。若KL终点比中点十胜率下降超过10个百分点，或任一族强制局率超过5%，明确标记后段退化/可靠性警报，不用验证选模掩盖。
- 若三对固定终点KL都比对照强且强制局率均不更差，称“在本轮条件下复现收益”；否则明确不一致。即使全部满足，也不称永不训崩、统计证明或跨生态泛化。
- 审计全部验证/重载/测试逐局计数和输入/权重哈希；六终点各挑最早失败（优先不购买零胜）、强制/截断、成功并去重，最多18回放，核验动作概率、价值与实际奖励。样例是诊断选取，不用于估计发生率。
