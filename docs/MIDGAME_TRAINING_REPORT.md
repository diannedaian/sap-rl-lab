# 40 宠训练报告：混合对手有收益，训练仍会失败

2026-09-08。**补规则、小试、三对训练、独立测试和回放审查均已完成。
得到可复现的实验模型，但还不能说训练稳定或已掌握完整 Turtle。**

## 最重要的结果

下面是两个未见学习型对手家族的平均**整局十胜率**，不是单场战斗胜率。
每模型每家族 1,000 局；检查点只用验证集选择，测试后没有换模型。

| 训练种子 | 纯脚本对手训练 | 50/50 混合训练 | 差值 |
| --- | ---: | ---: | ---: |
| 17101 | 9.75% | 52.30% | +42.55 个百分点 |
| 17201 | 45.65% | 54.85% | +9.20 个百分点 |
| 17301 | 0% | 0% | 0 |

三对平均 **+17.25 个百分点，2 对提高、1 对两组都失败**。收益很大一部分来自
第一对脚本组表现差，不能只报平均数。支持的是这套混合配方在本次留出对手上
有收益，不是“所有种子更稳定”或普遍泛化证明。混合组同时增加对手类型、
多样性和池容量，本轮未拆开消融。

## 回放教会了什么

- **循环仍存在。** 第一对脚本模型各家族强制整局比例 97.0%–98.1%；回放确认
  重复换位/冻结，每个动作仍扣 0.005。交付模型的成功回放也有重复状态，
  所以低强制率不等于没有浪费动作。
- **还有另一种失败：不买宠物，空队伍直接输。** 第三个种子两组从早期就只
  结束回合，跑满预算也未恢复；测试均每局六个动作、零胜、零强制。
  这是策略坍缩，不是环境报错；动作概率高度集中，但尚未用消融确定唯一成因。
- 混合组不总更稳定：17201 的强制率为 1.0%–1.3%，脚本对照为 0.1%–0.4%。
  本轮未设置 1% 硬门槛，也没有改写旧实验未通过验收的结论。

## 跑了什么、验证到哪

范围是普通商店到 Tier 3、完整 Tier 4 升级依赖，共 **40 宠**；不是正常 Tier 4
商店或完整 60 宠，部分官方客户端边界仍待复核。小试约 105 万步，平均胜场
0.05 → 4.06，十胜率 5.6%，当时仍低于脚本基线。

正式配方：小 Maskable PPO、每动作 −0.005、30 动作强制战斗；三脚本＋三历史
模型阵容等权，每场战斗抽来源；新环境从零训练，三个配对种子。六个对手生成者
各 4,194,304 步、六候选各 8,388,608 步，正式合计 75,497,472 次决策。
最多两个本机 CPU 工作者，正式生成/训练/测试约 **2 小时 56 分**，审查另计。

727 项测试通过；最终源码重跑的 6,000 场合成战斗重复一致、160 局可达整局精确回放。
全部六模型在测试前重载验证通过；30,000 条测试记录重新计数一致、均零截断；
42 个诊断回放精确复现；交付模型用封存源码重现全部 400 局验证。
诊断回放按结果抽样，不用于估计总体比例。学习型测试池仍共享算法/脚本生态，
交付模型两学习型家族分别有 37/12,680、2/13,395 场使用较早回合阵容桶，
晚期覆盖和存活偏差并未消失。
