# KL长时程复核 · 2026-09-13纽约晚间

**这一轮复现了收益：3/3对KL模型在固定终点都更强、强制率不更差；训练后半段仍在进步。可以继续保留KL，但不能说完全消灭循环或永远不会训崩。**

## 最重要的结果

每模型同样追加4,194,304决策。学习型十胜率为两个学习型对手族共400局中达成10胜的比例；强制率为五族共1,000局中至少一次耗尽30动作、被强制开战的比例。

| 来源种子 | 原PPO十胜率 → KL | 原PPO强制率 → KL |
|---|---:|---:|
| 17301 | 52.50% → **71.50%** | 96.5% → **0%** |
| 204101 | 60.25% → **78.50%** | 42.4% → **0.6%** |
| 204201 | 75.00% → **77.75%** | 0% → **0%** |
| 三种子平均 | 62.58% → **75.92%** | 46.30% → **0.20%** |

不是只挑最好检查点：固定中点209.7万步→终点419.4万步，KL三支十胜率分别57.25→71.50%、74.00→78.50%、76.25→77.75%。没有触发预先规定的“终点较中点跌超10个百分点，或终点任一族强制率超5%”警报；但这不等于每次验证都单调提高。

按各自验证集选择的版本比较，KL也**3/3对胜出**：71.50/74.00/77.75%，对照55.50/61.75/72.25%。没有用测试结果重选；例如204101的验证选择仍是中点74%，不会因为测试终点78.5%更高就偷偷更换。

## 训了什么、学到了什么

- 从此前三个BC→PPO的315万步健康权重重新分叉，用新继续训练采样seed97301/97302/97303。**没有新BC数据、没有再做BC，没有改奖励或环境。** 唯一算法差异为KL early stopping开/关。
- 六支完整训练共25,165,824决策，流水线含验证/测试/审计耗时**1小时39分17秒**。这次没有中断。旧模型、上轮中断证据和旧最佳均保留，没有自动替换交付。
- 实际KL中位数由对照0.031–0.045降到约0.009；KL梯度更新总数少约**67.85%**。同环境步数不等于同梯度预算，因此仍不能排除更远未来再次退化。
- 每局平均换位82.7→24.8次，冻结切换59.4→7.3次；宠物购买（含商店合并）22.3→21.4次，食物购买11.2→13.0次。不是靠完全不买东西来省动作。

## 还存在的问题

一个KL成功回放仍连续对同一对位置换位10次，最高概率99.81%，之后主动结束回合，没有撞上动作上限。**强制率低不代表没有循环；学到的战斗实力与操作效率需要分别评价。**

对照还有一个504动作、338次换位、12次强制开战的10胜回放。它说明：严重浪费动作的策略仍可能赢，不能只看十胜率；也不能把所有循环简单解释为“价值估计全错”。

仅三对新采样种子，复用了旧起始权重和已研究对手生态；不是全新初始化或独立生态泛化证明。目前仍40宠物、普通商店Tier1–3、Tier4仅升级奖励。报告的0%都是有限样本观测值，不保证真实发生概率为0。

**结论：保留KL作为当前工作配方。这轮稳定性复核可以收尾，后续不必为了宣称“永不崩坏”无限追加训练；扩环境时继续保留可靠性指标、验证选模和旧模型对照。** 没有启动下一项实验。

核验：54份精确验证检查点、8,800局重载、22,000局测试；52,400条逐局记录独立复算、13份回放2,170动作审计；53个worker退出码均0，所有重载完成后才启动任何测试。[详细证据](KL_LONG_EVIDENCE.md)；[面试准备](INTERVIEW_RL.md)。
