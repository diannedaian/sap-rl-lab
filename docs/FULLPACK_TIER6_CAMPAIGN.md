# Tier6全开放：持续训练至80%筛查通过

本阶段对应用户的完整目标，而不是再把Tier5的分数当作最终结果。

## 固定范围与配方

- 0.46版60只宠物、Tier1–6普通商店、18种普通食物、40回合上限。
- 接续本次Tier5课程的三条谱系；有合格验证检查点时用它，否则固定终点仅作为训练
  初始化，不包装为交付模型。迁移逐项核对词表、动作、环境，保持权重与推理一致。
- 新建完整包的三类脚本池和7支独立学习型对手：3训练、2验证、2测试。
  七支对手分别BC20轮加1,048,576 PPO步；固定终点取样，不按候选测试成绩换对手。
- 候选直接继承课程权重，不重复BC；首段各2,097,152步，之后每段各1,048,576步。
  每段从该谱系上一终点续训，重新建立Adam、改变训练采样种子；不称优化器精确恢复。
- 保持KL0.01、MLP、奖励、8环境×256、学习率等已有recipe。
- 采用已经测试的ContinuingGuard：交付仍≤5%强制率；学习只因实际截断、技术异常
  或连续3次严重退化而停，不因略超5%或正常段预算完成而停止整项工作。

## 自动继续与资源边界

`scripts/train_fullpack_tier6_h40.py`在首段完成后自动追加下一段，不等待用户重新批准。
同时最多2个CPU worker，每个训练模型1线程；每批4小时、单模型1小时保护。
磁盘不足20GiB停止并保留文件，不自动清理旧结果。不使用GPU、不上传或覆盖旧模型。
在安全停止时写明确原因；进程退出或正常跑完一段都不是目标完成证据。

## 选模与80%口径

- 每262,144步，固定验证种子119000000，每家族200局。
- 每条谱系在所有完整包段的验证记录上重放原严格选模器；不读取测试分数选检查点。
- 三支均有合格检查点且学习型平均验证十胜率达到80%后，才打开测试。
- 对两个独立学习型测试族各500局×3模型，共3,000局，平均十胜率≥80%；
  同时检查全部5个测试族的可靠性。不能取最高seed或仅看固定终点替代三模型选模均值。
- 测试种子固定120000000。若未通过，保持配方继续学习；若选模三元组没变，不重复测。
  因测试用于何时停训，最终报告必须披露适应性查看测试的限制。
- 筛查通过写`reached80_screen.json`，仍明确`confirmation_pending=true`，
  接着由本任务执行额外未看过对局的确认与完整证据审计，不自动宣称目标完成。

新阶段的`campaign.json`是对复用的基础准备协议中“全新候选BC/不自动扩展”等字段
的显式覆盖：基础工具只负责生成数据和对手，实际候选配置、环境契约、初始化、
学习停止标准均在新阶段封存。历史源码和实验协议保持原样。
