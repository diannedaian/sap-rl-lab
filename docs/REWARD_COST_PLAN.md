# 40 宠奖励成本对照：批准后固定的有界小试

用户于 2026-09-08 批准三对模型、共约 1,258 万次决策的本机 CPU 对照。
这是新预算，不改写上一轮负结果；不是扩大到 Tier 4 商店或完整 Turtle。

## 假设和唯一处理差异

A `all_actions`：每动作 −0.005，换位无额外成本。
B `swap_only`：只有换位 −0.005，其余动作无额外成本。
因此两边换位本身的成本相同，B 去掉购买、合成、刷新、冻结、结束回合等
非换位动作的成本。若 B 改善，不能直接断言只是购买成本导致；冻结免费也可能
使循环恶化。禁止临时增加剩钱罚分、购买奖金、动作屏蔽或改变游戏规则。

两边 entropy=0、成功额外奖励=0，保留现有游戏胜负奖励和 30 步强制战斗。
PPO 学习率 3e-4、gamma=1、GAE=0.95、8 个 dummy 环境、rollout 256、
batch 256、每进程 Torch 单线程，CPU。现有 v5 40 宠正常商店到 Tier 3，
Tier 4 仅升级奖励依赖；原训练实现和旧实验冻结文件不改。

## 保存和比较

每次验证保存当时准确权重、训练配置副本及张量摘要，含同一步数的最终更新
前后两个不同版本。保存层在本实验独立工作进程中包装评估，不改原 PPO 更新、
采样或选模规则；测试验证保存前后随机数状态和策略张量不变。

主要比较固定预算**最终权重**。次要报告原验证胜率优先规则所选权重，以及
全曲线；不事后新增可靠性筛选来隐藏最终退化。每个模型的所选与最终权重均
重载验证各 400 局（共 4,800），逐局一致后才开诊断测试。即使二者相同也记录
绑定关系，不能把它们当独立训练重复。测试报告 raw game reward，不用两臂
不同的 shaped return 排名；回放另按各自实际成本核对训练目标回报。

所有种子逐项报告：无购买零胜失败、十胜率/平均胜场、强制整局率及每战斗强制率、
冻结/换位/购买次数、截断、平均动作数。最终与所选均展示，不只报平均。
每个最终模型从验证集挑最早空队失败（否则普通失败）、强制/截断、成功各一例，
去重后最多 18 回放，检查动作概率、训练奖励和状态 value。诊断样本不当总体比例。

## 如何作决定

本轮只能建议是否值得做以后独立长确认，不自动确认扩张 recipe。
进入下一确认的候选筛查：三个 B 最终模型在验证及诊断测试各家族均无购买零胜
率 ≤1%、强制整局率 ≤2%、截断为 0；三个配对的学习型诊断测试十胜率差均
非负，平均胜场也均不低于 A。全部失败/缺失均保留，不放宽门槛。
